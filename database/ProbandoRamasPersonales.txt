-- Creacion de ramas
1. Cambiar a main  
    git checkout main
    git pull origin main
2. Crear la rama personal
    git checkout -b (NombreDeLaRama)
3. Editar el código

4. Guardar los avances
    git status
    git add (nombre de la carpeta o archivos editados/creados)
    git commit -m "descripcion breve"
5. Subir el avance
    git push -u origin (NombreDeLaRama)
6. Pasos extras
    Entrar al repositorio de GitHub
    Hacer click en Compare & pull request
    Revisar que diga: base: main - compare: (NombreDeLaRama)
    Hacer click en create pull request
7. Finalizando
    Hacer click en Merge pull request, si no hay errores
    Volver a VisualStudio y volver a main
    git checkout main
    git pul origin main
